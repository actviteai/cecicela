# ceciCela for Grok Projects: setup

1. Create a Project named **ceciCela**.
2. Paste `INSTRUCTIONS.md` into the Project's instructions. (The build keeps it under 8,000 characters; check Grok's current limit in the Project settings.)
3. Add every file in `knowledge/` and `graph-player.html` to the Project's files.
4. When the graph is on and Grok Studio opens from the Project chat, Grok builds the player there once and edits it in place each turn. If Studio does not open, it uses the text screen.

Sharing: check the Project's share action at release time. If it exists, share the Project and link it from the README; if not, this kit is the route.
