# ceciCela in Agent Builder: the fields

Generated by `npm run chat:build`; copy each value into the Configure tab.

**Name** (30 characters at most): `ceciCela`

**Description** (1,000 at most):

Plan it, prove it, fix it. trouble runs a four-roles Bayesian debug protocol on a stuck bug; ceci plans a goal as a job graph with human gates; cela reviews whether a change is really done. The chat entry point to the ceciCela coding-agent skills: in chat they cannot read files or run commands, and they say so.

**Icon:** `brand/png/seal-192.png` (PNG, 192x192, transparent, under 1 MB).

**Instructions:** the whole of `INSTRUCTIONS.txt` (the build keeps it under 8,000 characters).

**Knowledge:** every file in `knowledge/` (upload from device; 10 files, the limit is 20). No websites, SharePoint, or connectors.

**Capabilities:** leave Web search, Code interpreter, and Image generator off.
